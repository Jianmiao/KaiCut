# 原生源预览提交前过期帧拦截

本批处理“队列已经取出一帧，但还未调用原生绘制，素材却已关闭或定位到新代次”的窗口。默认播放器、UI、项目格式及sidecar不变。

## 行为

主线程在绘制前重新检查队列是否关闭、是否存在终止错误，以及任务与帧的render epoch是否仍匹配。已失效任务单独记为提交前丢弃，不调用平台绘制、不产生MediaAck，也不伪造HRESULT或画面已接受的结果。如果新代次已有待处理帧，继续安排它的回调。

检查不持队列锁进入系统调用。若退役恰好发生在最后检查之后，已经发起的调用仍由原有提交后检查处理；本批不承诺彻底消除该竞争窗口，更不承诺中断驱动调用。

## 验证方式

复用隐藏验证入口，在真实任务出队后、提交检查前设置一次性停留点。后台通过正式原生命令关闭或定位，记录队列退役但命令仍未完成，再释放停留点。验收要求同一帧出现在独立丢弃记录中，Present和播放确认计数不增长，随后新素材或新位置能继续播放。

| 场景 | 预期结果 |
| --- | --- |
| `prepresent-cancel` | 旧sink关闭，帧按closed丢弃；关闭完成后B从零准备并播放至少300ms |
| `prepresent-seek` | render epoch前进，帧按stale-epoch丢弃；同一素材在3秒准备并播放到至少3.3秒 |

停留点只在显式隐藏隔离debug参数下启用，最多10秒。提交前与提交后的停留边界互不抢占；验证异常时，尚未被帧认领的停留点会作废，已经进入的停留点会释放并保留失败标记。正常运行不启动该调度。

## 实测

2026-10-18，四个独立隐藏实例通过，关闭两轮（PID32528、26344）、定位两轮（PID16440、42760）。每轮恰有一个已取出的旧帧在平台调用前被拒绝；Present、ACK、遮挡与迟到完成计数均没有因这帧增长。关闭后B从零准备并播放；定位在3秒准备后继续播放超过300ms。停留窗口为16、17、12、9ms，只是受控排程，不是自然取消延迟。

正式批次为`src-tauri/target/native-source-validation/prepresent-085607ec-3a3d-4879-9ca8-f2f4afb5984a`。独立报告`prepresent-verification-4858f2d5-a9b5-48ed-a0c4-5c1909a86c52.json`为`ok=true / complete=true`，SHA-256为`217f18ea5b8580e7e2399dcc6d0f4b5fb2c8fade2dd5f6538c8bbb976d5f4362`。202项篡改检查全部拒绝，6个actor、24个解码子进程与18个profile探测进程均回收；68项源码、程序、前端、sidecar身份一致。103个历史进程PID的最终查询没有存活匹配，短寿命进程回收仍同时依赖原始join/reap台账。

同程序另通过旧媒体单轮回归（PID22716，41次Present、5次准备画面GPU读回、12个解码子进程）及提交后定位退役单轮回归（PID17268，旧结果Stale，39项篡改检查拒绝）。旧媒体验证器针对新增的独立丢弃记录补了严格计数守恒，原来的像素和时钟检查保留；2个有效样例及10个篡改样例自检通过。

工程检查：前端292项通过；Rust默认107项通过、6项忽略；原生feature388项通过、8项忽略。lint、前端构建、Rust格式以及内嵌前端的`native-preview-host,tauri/custom-protocol`构建通过。忽略项不计通过，Rust既有警告未清除。

## 正常控件回归中的未解决观察

首次正常控件回归（PID33376）在接近片尾的200ms段记录一次`underrunObservations=1`，独立校验按原有零欠载标准失败。该段接收9600音频帧，最终时钟与端点一致；所有59次主素材画面提交完成，skip、迟到和关闭结果均为0。无原始播放或清理错误，但现有记录不足以区分首次供音和中途供音，不能认定为EOF误报或证明由本轮检查导致。

同程序、同素材复测（PID46088）通过，包括定位、自然片尾、重播、切源和回退；这不撤销第一次失败。两份独立报告都保留，分别位于`target/native-source-validation/prepresent-controls-6a6184d2-32ae-44bf-8423-d454b1f2cd44/source-verification-ee3cb590-2f3c-4f22-ad85-3c8abd5517bd.json`与`target/native-source-validation/prepresent-controls-recheck-d31ae6e3-5cb7-4714-9799-e658112e56f0/source-verification-408efef3-2d5f-4dd4-acfd-f5b80193564b.json`（相对`src-tauri/`）。本批只确认提交前拦截，不能宣布无断音或整体实时资格通过。

下一步优先增加有界欠载事件，记录发生时已提交/剩余采样、padding、首次泵送与Start耗时，再复现定位。真实驱动故障、可见输出和物理同步保持独立验收。四轮仍有WebView `Chrome_WidgetWin_0`注销警告1412；未操作桌面或系统设备。
