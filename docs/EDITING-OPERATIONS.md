# 剪辑操作对齐清单

日期：2026-10-11。产品方向：剪映式布局与操作习惯，Apple 风格视觉；KaiCut 自有代码、Apache-2.0，媒体处理继续使用已审计 LGPL FFmpeg。用户要求不控制电脑，因此本轮只有后台自动测试与无窗口渲染，没有执行剪映或 KaiCut 的人工实机交互。

## 依据与确认程度

- 用户提供的剪映截图可确认区域布局、干净时间线画布、片段缩略图/波形位置及工具排列。截图不能证明鼠标手势、快捷键和所有边界行为。
- 此前只读确认本机剪映版本为11.5.0.14471，安装资源出现导入、分割、裁切、撤销/重做、吸附、主轨磁吸及波纹编辑的命令标识。没有把其源码或资源复制到 KaiCut，也未从标识推断完整算法。
- 本表是实现/验收清单；“按剪映习惯”不等于每项已经与剪映实机逐项核对。下方未验证的键位是 KaiCut 初始绑定，后续通过同版本剪映快捷键页确认。

## 本轮基础编辑

| 操作 | 当前行为与验收标准 |
| --- | --- |
| 添加 | 双击素材追加到第一个可用兼容轨道；检查器可选择目标轨道。视频/音频由Rust重新探测真实时长，图片默认5秒；离线/损坏/锁轨不添加 |
| 选择 | 单选时间线片段，在检查器查看片段起点、源入点、时长；不改变项目dirty或历史 |
| 播放头定位 | 点击/拖动标尺或空轨道；左右方向键逐项目帧，Home/End跳首尾。这里只改变编辑位置，不宣称画面已seek |
| 分割 | 所选片段内部按播放头分为两段；右段源入点正确递增，严格拒绝端点分割。左段只保留原淡入、右段只保留原淡出，超过子段长度时缩短，内侧切口不新增淡化 |
| 删除 | 普通点击单选，Ctrl/Cmd 增量选择或 Shift 选择同轨范围；Delete 可一次删除多个片段并保留空隙，Shift+Delete 执行按轨道波纹删除；不删除媒体文件或素材引用 |
| 副本 | 创建新片段ID并追加到同轨末尾。这不是完整复制/粘贴剪贴板流程 |
| 移动 | 拖片段改变位置/兼容轨道，也可在检查器输入项目帧起点。多选拖动同时保持时间差与同类型轨道序号差；所有目标轨必须存在且解锁，否则整组保持原轨、允许水平移动。组内锁轨不启动拖动；同轨重叠仍由 Rust 原子拒绝 |
| 裁切 | 左右边缘拖动，保持对侧边缘、至少一帧，不超源范围；检查器可精确提交源入点/时长。淡入淡出总长超出新时长时按比例缩短，延长片段不自动放大淡化 |
| 吸附 | 拖动时在6px阈值吸附播放头/片段边缘；主轨参考固定为 `video-1`，不写入项目且不可配置；Alt临时关闭。Rust只校验提交后的明确帧位置，不计算指针吸附。此功能与波纹编辑不同 |
| 撤销/重做 | Rust轨道快照历史，最多100步/16MiB；一次拖动释放只提交一次。Escape/指针取消不提交。新编辑清redo；导入、重命名不被时间线历史回滚 |
| 轨道锁定/停用 | 锁定阻止编辑；停用写入项目并在预览播放中静音音频轨，视频轨保留隐藏状态 |
| 缩放 | 按钮或滑块缩放标尺/片段；尺与片段按统一比例定位，头部固定，长项目按可视范围呈现 |

时间线主体为实色，无纵向格线、横向格线或伪波形；仅标尺、轨道头分隔与1px白色播放头。片段只显示真实素材首帧小图，不以同一张图冒充完整逐帧缩略条。音频片段在真实波形接入前使用纯类型色。

键位初值：Windows Ctrl+B分割、Delete/Backspace删除、Ctrl+Z撤销、Ctrl+Shift+Z重做；macOS代码使用对应Command修饰键，macOS设备仍待验收。输入框/中文输入/弹窗与菜单打开时不触发编辑快捷键。剪映同版本实际键位仍需核对，不能把这些初值称作已证实的完整剪映键位表。

## 项目格式与限制

- `.kaicut` v2单文件JSON新增 `sourceInFrame`、`sourceDurationFrames`、音频轨 `volume` 以及片段 `fadeInFrames`/`fadeOutFrames`。所有frame字段均为项目时间基、1倍速，源时间=frame×fpsDenominator/fpsNumerator；不等同于原素材解码帧号。
- 合法v1空轨项目与恢复点读入时迁移到v2，打开不写源文件。保存后旧版KaiCut会拒绝v2文件；需兼容旧版时先保留原副本。
- 最多2视频+2音频轨、10000片段、24小时时间范围、10MiB项目JSON。单轨不重叠；同轨片段源范围和素材引用必须有效。
- Rust持有权威状态，IPC带projectId/revision，拒绝过期命令。历史仅轨道，缩略图/probe/播放头/选择不写项目。
- 撤销后保守标记未保存，即使内容回到上次保存点仍需保存；当前不是无限历史或完整非线性编辑器。
- 重新链接当前片段或历史中使用过的素材时，重新探测源长度。过短素材拒绝替换；成功替换刷新源边界并清空旧时间线历史，避免撤销恢复出越界片段。静态图片5秒为初始时长，可延长到项目上限。
