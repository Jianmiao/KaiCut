# KaiCut UI 设计规范 v0.2

- **状态**：已认可，按 2026-10-06 高密度修订统一面板层次、字体和尺寸
- **产品形态**：当前以 Windows 为交付与实机验收平台的桌面视频剪辑工具；macOS 待设备后适配。Apple 风格仅作视觉参考。
- **设计方法**：使用 `$apple-web-design` 的 `plan` 模式制定，本轮以 `implement` 模式修订；组件优先采用 `shadcn-macos`
- **规范关系**：本文件定义设计规则，[DESIGN-TOKENS.md](./DESIGN-TOKENS.md) 是唯一数值规范，[UI-CHEATSHEET.md](./UI-CHEATSHEET.md) 是单页速查表；历史修订记录不作为并行方案。
- **实现边界**：本轮按用户视觉清单同步背景层次、预览、时间线及材质；业务能力仍按原阶段边界，平台实机验证以交付记录为准。

## 设计目标

让素材、画面和时间线成为视觉中心。按用户最新方向，工作台区域结构、操作位置与阅读顺序参考剪映；字体、灰阶、圆角、材质和反馈采用 Apple 风格。通过截图与自有代码实现，不采用剪映专有代码或图标。跨平台共享视觉规则，系统交互遵循所在平台。

首版暂按“本地项目、基础多轨剪辑、单项目工作台”规划。AI、云协作和专业调色不属于本版承诺，除非后续需求明确纳入。

## 需要先承认的产品风险

项目已有基础工作台骨架；本规范覆盖的完整剪辑工作流仍需分阶段实现与验证，不能把组件库示例或设计目标视为已交付能力。

`shadcn-macos` 可优先提供按钮、侧栏、标签、输入、选择器、对话框、菜单、滑块和进度等基础组件，但时间线、波形、视频预览、裁切手柄、轨道拖放和面板分隔器仍属于 KaiCut 的业务组件。组件库的外观也不等于完整的焦点管理、菜单键盘操作或平台无障碍支持，这些必须单独验收。

视频编辑器的主要成本在媒体生命周期、时间码精度、真实视频负载、导出失败恢复和当前 Windows 验证与未来平台适配，而不是毛玻璃效果。实现顺序必须先闭合这些流程，再做视觉微调。

## 页面层级与信息架构

### 一级页面

| 层级 | 页面或区域 | 核心内容与行为 |
| --- | --- | --- |
| 入口 | 项目中心 | 新建、打开、最近项目；显示路径、缩略图和修改时间 |
| 核心 | 编辑工作台 | 素材库、预览、检查器、时间线，围绕当前项目持续工作 |
| 任务 | 导出设置与任务列表 | 输出位置、格式、预计资源需求；显示进度、取消、失败原因与重试 |
| 全局 | 设置与快捷键 | 外观、可访问性、缓存、播放性能和快捷键 |
| 恢复 | 项目恢复与媒体重新链接 | 从项目中心或工作台进入，直接说明问题和恢复方式 |

### 编辑工作台

工作台采用五区布局：

- **顶部工具栏**：项目名称、保存状态、撤销/重做、导出。
- **左侧素材区**：素材搜索、导入、列表/缩略图切换。素材显示可用、离线、处理中等状态。
- **中央预览区**：画面、播放控制、时间码、缩放；画面四周使用稳定中性色。
- **右侧检查器**：随当前选择显示片段、音频、字幕或项目属性；无选择和多选有明确状态。
- **底部时间线**：轨道头、片段、播放头、时间标尺、缩放与吸附控制。

唯一默认尺寸：Windows 集成标题栏/工具栏 **44px**、左侧素材区 **320px**、右侧检查器 **300px**；工作台外边距和区域间距均 **8px**。时间线轨道行高 **34px**、轨道头宽 **96px**，工具行 **36px**，标尺 **24px**，默认高度 **300px**。两条垂直分隔器调节素材区180–460px、检查器220–380px；空间不足时收缩辅助区，桌面最小窗口下保证播放器至少300px。时间线水平分隔器调节220–520px，恢复布局回到320/300/300px。Windows窗口按钮仍占用同一44px标题栏行；macOS保留原生标题栏。

素材区使用现有导入、搜索、网格/列表入口；不新增未实现的贴纸、会员、AI或运营模块。未选择素材时，检查器显示当前项目名称、路径、帧率与素材数；选中后显示真实素材属性。时间线仅一条工具行，项目名/轨道数/帧率放底部，空项目不展示伪片段或假波形。

窗口变窄时，优先折叠辅助面板；素材区与检查器改为按需切换，保留预览与时间线的可操作区域。大字号和系统缩放下，表单允许重排，不能通过缩小文字维持四栏。

### 必须设计的状态

- 首次使用、无素材、处理中、加载失败、媒体离线。
- 已保存、保存中、保存失败、异常退出恢复。
- 导出排队、运行、取消中、失败、完成。
- 片段无选择、单选、多选，以及素材、片段、轨道和画布之间的选择切换。

导出任务采用提交时的项目快照，后续编辑不改变该次输出。首版不默认承诺退出应用后仍可继续导出；关闭项目或应用时，必须明确提示未完成任务的处理方式。

## 材质与毛玻璃范围

按本轮视觉修订，毛玻璃用于工具栏、素材侧边栏、菜单和短小弹出层；其他编辑内容保持实色。侧边栏是本轮明确新增的材质范围。

| 区域 | 材质决策 |
| --- | --- |
| 工具栏、素材侧边栏 | 桌面原生材质，透出窗口后方真实内容；失败或关闭透明度时实色 |
| 菜单、短小弹出层 | 可使用受控毛玻璃，与触发位置保持空间联系 |
| 项目列表、素材卡片 | 稳定表面；素材侧边栏容器采用原生材质 |
| 时间线、波形、字幕编辑 | 时间线、空轨道与轨道头统一 #202022；轨道头96px、行高34px、工具行36px。内容画布不画纵横网格，时间刻度仅在顶部标尺；缩放时调整主次刻度密度。轨道头和区域边界保留1px分隔，白色播放头1px无三角，视频/音频用低饱和蓝灰区分。 |
| 检查器、属性表单、导出设置与对话框 | 实色背景 |
| 视频预览 | 容器 #1A1A1C、画面周围 #0E0E10；外容器与素材/属性/时间线一致使用10px圆角与1px边框，不加阴影，画面本身无装饰边框。底部浮动控制条保持左时长、中播放、右显示控制；当前静态首帧不启用播放，预留控制条遮挡区以完整展示图片，窄窗口收起未开放的右侧操作 |

菜单 CSS 毛玻璃默认背景不透明度 90%、模糊 14px。当前工具栏与侧边栏在受支持的 Windows 上使用 Acrylic，macOS NSVisualEffectView 分支保留但待设备后验证。原生模糊半径由系统管理，不叠加全窗口 CSS blur。原生链路成功后，根背景透明、内容面板实色；仅控制层加可读性染色。失败时完整回退到实色。参数见 [DESIGN-TOKENS.md](./DESIGN-TOKENS.md)。

KaiCut 固定深色单主题，不提供浅色或跟随系统选项。该选择是本项目的产品决策，不代表专业软件必须只有深色。导出是唯一蓝色实心主操作；导入与弹窗确认使用次要按钮，焦点/选择等辅助状态仍保留必要颜色。

主背景 #1C1C1E，查看器容器 #1A1A1C、画面周围 #0E0E10，侧边栏和检查器 #2A2A2C，时间线 #202022，四区边界1px rgba(255,255,255,0.10)。原生材质区域以侧栏基色85%染色，即 `rgb(42 42 44 / 85%)`，合成结果仍会随后方内容变化。Windows 首发使用无系统装饰窗口，由顶部栏右侧唯一提供最小化、最大化/还原和关闭按钮；不使用 macOS 红黄绿按钮，标题栏空白区负责窗口拖拽。Tauri 配置与运行时均关闭原生装饰，避免原生按钮和自绘按钮重复；macOS 后续适配时单独恢复原生标题栏策略。品牌标识与应用图标统一使用用户提供的影片、播放和剪刀组合图形；不再使用K字母或单独剪刀字形。底部状态栏用主文字色。界面图标统一线条风格，操作图标16px、stroke1.6；未保存使用tertiary，导出图文间距8px。查看器标签与“1080p/适合窗口”均为11px tertiary。

素材区采用中性灰导入面板，图标容器32px、文字13px；播放器空态图标18px、文字12px。控制条使用 `--kc-color-preview-controls: rgb(26 26 28 / 82%)`，减少透明度时回退为查看器实色。时间线工具行左侧撤销/重做、分割/删除/创建副本、音频混音/速度，右侧吸附/缩放；Lucide图标16px、stroke1.6，未开放操作禁用并提供说明。空项目只显示真实空轨道和添加指引；已有片段来自项目数据，音频波形未生成时不画假波形。

### 强调色与文字

唯一蓝色主操作为**导出 `#0066CC`，文字 `#FFFFFF`**。悬停使用 `#005CBA`，按下使用 `#004F9E`，文字均保持白色；这是同一套强调色的交互状态。默认蓝底白字对比度约 5.57:1，满足普通文字 4.5:1 的要求。

Accent 用于主操作填充；焦点轮廓和轻色选择背景使用独立语义 token。深色背景上的普通文字链接使用主文字色并加下划线，不直接将按钮填充色当文字颜色。透明度、叠加状态与禁用状态分别验收，不把单个纯色配对的结果扩展为所有组件已通过对比度检查。

### 圆角与风格边界

| 类型 | 唯一圆角 |
| --- | ---: |
| control：按钮、输入框、选择器 | 6px |
| surface：面板、卡片、属性分组 | 10px |
| popover：菜单和短小弹出层 | 10px |
| dialog：对话框 | 12px |

缩略图沿用 control 圆角，不新增独立尺寸。禁止大圆角、胶囊化普通按钮、重阴影、紫色渐变、居中大标题和毛玻璃滥用。界面以对齐、细分隔线和有限的轻阴影建立层级；页面标题与内容对齐，项目名保持普通工具栏文字尺寸。

在不支持模糊、用户减少透明度或低性能模式下，切换到实色背景，同时保留边界、层级和对比度。不能只依赖 `prefers-reduced-transparency`，因为桌面 WebView 对该偏好的支持并不一致，KaiCut 还要提供应用内独立开关。

## 排版与间距系统

字体完全使用系统字体栈，不引入用户字体包，不设置自定义字体别名或本地字体加载规则：

- macOS：`-apple-system, BlinkMacSystemFont, system-ui`，由系统为中文自动选择苹方，不显式指定字体文件或字族。
- Windows：`"Segoe UI", "Microsoft YaHei UI", system-ui`。拉丁字符使用 Segoe UI，中文默认回退到微软雅黑 UI，不请求 Apple 字体。
- 未识别平台：`system-ui, sans-serif`。
- 数值和时间码：`ui-monospace, "Cascadia Mono", Consolas, monospace`，使用等宽数字。

Tailwind 的 `font-sans` / `font-mono` 映射到项目 token，确保 Sidebar 与其他 shadcn-macos 组件一致，避免局部回到默认字体栈。

| 文本角色 | 字号 / 行高 | 字重 |
| --- | ---: | ---: |
| 项目中心标题 | 24 / 32px | 600 |
| 面板标题 | 12 / 20px | 600 |
| 常规操作、表单、列表 | 13 / 20px | 400–500 |
| 次要信息 | 12 / 18px | 400 |
| 时间码、数值 | 12 / 20px | 400–500，等宽数字 |

中文长说明适当增加行高；文件名截断后提供完整名称和路径的可访问入口。关键状态和错误原因不使用小号淡灰文字。

统一间距采用 **4、8、12、16、24、32px**：

- 图标与文字：8px。
- 同组控件：8px。
- 面板内边距：16px。
- 不同功能组：24px。
- 项目中心等宽松页面：24–32px。

常规桌面控件视觉高度建议 32px，舒适密度 40px；触控模式目标区域至少 44×44px。小图标和裁切手柄可扩展命中区域，但不能相互覆盖。

上述控件/命中尺寸不是另一套窗口布局；工具栏与侧面板的默认尺寸始终使用前述唯一值。仅在粗指针触控模式下，轨道行最小高度扩展到44px，避免锁定按钮命中区重叠；播放控制条内部重排，仍覆盖于查看器底部。

## 动效默认值

以下数值是 KaiCut 的建议初值，不是 Apple 官方定值。

| 操作 | 默认时长 | 行为 |
| --- | ---: | --- |
| 按下、悬停、状态反馈 | 120ms | 主要改变颜色与透明度 |
| 菜单、小弹出层 | 160ms | 短距离显现，起点关联触发控件 |
| 对话框、检查器展开 | 220ms | 轻微位移、淡入；低频弹层允许克制回弹 |
| 分割、逐帧、撤销、拖拽 | 0ms 额外过渡 | 立即反映操作 |
| 播放头跟随、时间线缩放 | 直接更新 | 不使用缓动追赶 |

普通进入动效使用 `cubic-bezier(0.23, 1, 0.32, 1)`。动画可中断，不延迟命令执行，不锁住输入。优先动画化透明度和变换；不为日常剪辑添加弹跳、视差或装饰性循环动画。

“减少动态效果”应关闭位移、缩放和弹性效果，可保留不超过 100ms 的颜色或透明度反馈。该设置不改变用户素材的正常播放。

## 跨平台行为

当前以 Windows 系统交互和真实窗口为准；以下 macOS 约定仅作为未来适配原则，不是本期交付门槛：

- 使用各平台真实的窗口控制、系统菜单和文件选择器。
- 快捷键按平台显示与执行，不能只把 `Cmd` 全局替换为 `Ctrl`。
- Windows 不使用假的 macOS 红黄绿窗口按钮。
- 处理 Windows 高对比度、键盘菜单导航、系统缩放和路径展示。
- 主编辑区的控件密度可以共享；平台窗口装饰、菜单位置和系统级行为不能强行统一。

## 可访问性与降级策略

以 WCAG 2.2 AA 的相关要求作为 Web UI 验收基线，同时验证桌面辅助技术。

### 键盘与焦点

- 能够仅用键盘完成导入、选择、移动、裁切、分割、撤销和导出。
- 文本编辑和中文输入期间，不误触时间线快捷键。
- 弹窗打开后合理定位并限制焦点，关闭后返回触发位置。
- 菜单、标签页、选择器和时间线操作提供可预测的键盘行为。

### 时间线语义与非拖拽闭环

时间线不能只依赖 Canvas 或拖拽。辅助技术应能读取片段名称、轨道、起止时间和选择状态。除拖拽外，还要提供“添加到时间线”、目标轨道选择、起止时间输入和移动命令。

非拖拽闭环至少包含：键盘选择片段、移动到指定轨道和时间、调整入出点、拆分、排序、撤销以及明确的状态反馈。

### 对比度与状态

- 普通文字至少 4.5:1，大字至少 3:1。
- 识别控件和状态所需的非文本视觉信息至少 3:1。
- 选择、离线、静音、锁定和错误不能只靠颜色表达。
- 导出状态适度播报，避免连续进度刷屏。

### 降级模式

| 条件 | 表现 |
| --- | --- |
| 减少透明度或不支持模糊 | 切换实色背景，保留边界与层级 |
| 减少动态效果 | 移除空间运动，保留必要反馈 |
| 高对比度 / Windows 强制颜色 | 使用系统颜色与明确轮廓 |
| 低性能模式 | 关闭玻璃和装饰阴影，减少非必要缩略图更新 |
| 系统偏好无法读取 | 使用应用内独立开关并保存选择 |

## 组件与实现边界

优先复用 `shadcn-macos` 的 Button、Sidebar、Tabs、Input、Select、Dialog、Sheet、Menu、Slider、Progress 等组件，并补齐焦点管理、键盘操作、减少动态效果、无透明度模式和低性能降级。

以下组件需要 KaiCut 自行实现：

- 时间线与轨道头
- 波形和音频编辑显示
- 视频预览与播放控制
- 片段选择、移动、裁切和吸附
- 裁切手柄与可调整面板分隔器
- 时间码输入与帧精度规则

## 项目生命周期与媒体规则

在编辑器实现前，需要确定并记录：

- 自动保存频率、保存失败提示和异常退出恢复。
- 媒体文件移动后的重新链接、不可读取格式和代理文件失败状态。
- 素材帧率与项目帧率的关系、时间码显示方式和帧单位。
- 导出任务是否持有提交时的项目快照，关闭项目或应用时如何处理任务。
- 预览性能等级、缓存位置、磁盘空间不足和导出失败后的重试入口。
- HDR、色彩管理和代理媒体是否属于首版范围。

## 实施顺序

1. 建立主题、字体、间距、动效和可访问性变量，验证 Windows 实际组件行为。
2. 完成项目中心与工作台布局，包含小窗口、大字号及空态。
3. 串起“导入 → 剪辑 → 保存 → 导出”，补齐媒体重新链接、恢复与失败流程。
4. 在真实视频播放和拖动负载下检查材质性能，随后进行视觉微调。

## 验收计划

### 页面和状态

- 项目中心：首次使用、最近项目、新建、打开、路径错误。
- 工作台：无素材、单选、多选、离线、处理中、无选择、保存失败。
- 时间线：键盘选择、移动、裁切、分割、撤销、吸附和非拖拽替代。
- 导出：排队、运行、取消、失败、完成、重试和磁盘空间不足。

### 平台与偏好

- Windows 实机；macOS 待设备后单独验收。
- 高密度修订使用包含窗口边框的真实 Windows Tauri 截图，与 Apple 官方 Final Cut Pro Mac 参考图并排比较；参考图不是 KaiCut 的 macOS 实机验收结果。
- 固定深色；启动、旧主题偏好迁移和系统配色变化都不得切回浅色。
- 100%、150%、200% 系统缩放。
- 当前验证键盘、NVDA、减少动态效果、减少透明度和高对比度；VoiceOver 延后到 macOS 阶段。
- 玻璃开启、应用内关闭、浏览器/WebView 不支持模糊和低性能模式。

### 性能与工程验证

- 真实视频下播放、拖动、缩放和波形更新保持可操作。
- 关闭材质后功能完整，且播放和时间线判断不受装饰效果干扰。
- 应用建立后执行项目已有的 lint、类型检查、测试和构建命令。
- 在真实窗口中完成视觉、键盘、焦点和辅助技术验证；未实际验证的项目必须明确标记。

## 非目标与保留边界

- 不引入用户字体包，不捆绑 Apple 字体、Apple 符号、系统截图或原生资源。
- 不把 Windows 做成 macOS 窗口的视觉复制品。
- 不把全局毛玻璃作为默认背景。
- 不在本阶段改变路由、数据模型、媒体引擎、导出编码器或认证方案。
- 不因组件库已有示例就宣称 KaiCut 的时间线、预览或导出已经实现。
