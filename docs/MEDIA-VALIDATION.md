# 媒体信息与静态预览验证（2026-10-10）

本轮交付：当前项目中的视频首帧与图片预览、素材库按需缩略图、错误/重试/离线提示、单视频/音频播放、相邻片段连续衔接、空隙播放头推进、音频轨跟随、漂移校准、运行时波形，以及基础多轨混音（轨道音量/静音、片段淡入淡出）。基础导出已在后续 M3 批次接入，详见 M3-EXPORT-PREFLIGHT.md。

单视频/音频预览使用受控 Tauri `asset:` URL、`<video>` / `<audio>` 元素、播放/暂停、时间更新和播放头回写；未选中片段时从素材0秒播放，选中片段时按 `sourceInFrame + (playhead - startFrame)` 定位。音频元素按同一项目帧计算轨道音量、静音和片段淡入淡出；连续跨片段播放已接入，导出范围与证据见 M3-EXPORT-PREFLIGHT.md。

## 实现边界

- 复用已经审计的 Windows LGPL FFmpeg/ffprobe，二进制和哈希未变。新增 Rust 直接依赖 base64 0.22、sha2 0.10（版本固定在 Cargo.lock）。
- UI 仅发送素材 ID；Rust 从当前项目查询路径，校验源文件大小和修改时间，并通过固定参数执行 FFmpeg。没有给 WebView 开放任意本地文件访问。
- 视频取首帧、图片按原透明度生成 RGBA PNG；最长边 960px、单图上限 4 MiB，后台串行解码，单次进程截止 10 秒。按显示比例缩放并应用视频旋转，输出方形像素，整数尺寸会有取整误差。这是浏览预览，不是原画或 HDR 色彩管理预览。
- 磁盘缓存位于应用缓存目录 thumbnails/，键包含 canonical 路径、大小、精确修改时间和转换版本；最多 128 MiB/512项，新增时清理最旧生成项。源码生成文件采用原子替换；缓存不可用不会改动项目。
- 前端最多两项在途请求、64 张且总字符串预算 32 MiB；优先选中素材，旧项目/旧引用结果不会覆盖当前结果。只加载可见卡片和选中素材；保存和重命名保留运行时信息及选择。
- `.kaicut` schema v2 持久化音频轨音量和片段淡入淡出；probe、缩略图、data URL 和媒体字节仍不写入项目文件。检查器显示源时长（时分秒.毫秒），不把它冒充逐帧编辑时间码。

## 自动验证

- Rust 单元测试覆盖路径/大小/修改时间缓存键、离线/changed/音频、文件大小与 PNG 尺寸、受控缓存清理；ffprobe 解析与项目持久化测试继续保留。
- 显式运行真实 sidecar 测试，覆盖中文空格 MP4、90°旋转、SAR 4:3 非方形像素视频、透明 alpha=0 PNG、含 `%03d` 的字面图片路径、缓存命中与失效、损坏文件、离线和音频无画面状态。
- 前端测试覆盖两项并发/去重、缓存驱逐、不同项目复用同一 ID、重新链接旧 probe/thumbnail 结果、保存/重命名保选择、可视区懒加载、静态首帧说明、禁用播放、错误重试与缺失素材隐藏旧画面。

真实 sidecar 用例依赖本地生成的视频样本，默认标记 ignored。可用 PowerShell 显式运行：

```powershell
$env:KAICUT_THUMBNAIL_TEST_VIDEO = 'E:\ffmpeg-build\records\n7.1-mf\probe-output.mp4'
cargo test --manifest-path src-tauri/Cargo.toml --locked -- --include-ignored
```
