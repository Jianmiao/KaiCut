# 时间线密度与预览性能基线

日期：2026-10-16。Windows x64、真实 Tauri/WebView2、隐藏且不获取焦点的独立 MCP 实例。没有使用 computer-use。本轮建立首批长素材/多片段基线，并修复已复现的多选渲染问题。

**本轮通过的是合成负载的性能回归，不是 M2 的完整音画同步验收。** `TASKS.md` 的“10 分钟代表性素材漂移小于一帧”和可见交互 60fps 目标仍待完成，本轮没有降低它们。

## 方法与范围

- 生成 90 秒、1280×720、30fps 的动态 testsrc2 H.264 视频，以及 90 秒 48kHz 单声道节拍 WAV，约 31 MB。使用已有 LGPL FFmpeg 与 Windows h264_mf，不使用用户媒体。
- 连续项目：2 片段，实际采样约 65 秒播放。
- 多片段项目：30 分钟时间线、300 视频＋300 音频片段，每段 6 秒，复用上述素材。实际采样约 24 秒，跨过 5 个视频片段；不是连续播放了 30 分钟。
- 密度项目：30 分钟、3,000 视频＋3,000 音频片段，每段 18 帧；验证首/中/尾定位及选中 1,000 个屏幕外片段，不宣称验证了该密度的连续播放。
- 每次 MCP 检查包含约 32ms 的既有页面确认等待及传输开销。页面采集耗时与请求往返耗时分开记录。
- 媒体元素 currentTime 的差不等同声卡输出或屏幕呈现延迟。隐藏窗口的视频累计/丢帧计数只作诊断，不作为可见窗口 FPS。

## 复现与修复

优化前真实基线失败于：选中屏幕外片段绕过时间线视口裁剪。组件回归也复现播放头每帧更新带动整个 App 重渲染，以及多选重复扫描片段/轨道的平方级开销。

修复：App、工具栏、检查器只订阅实际使用的状态；缓存片段→轨道索引、素材索引和选择 Set；可见片段列表按项目、视口和拖动状态缓存。屏幕外选择仍保存在状态里，不再强制挂载全部 DOM。保留当前键盘焦点与活动拖动节点，屏幕外多选仍参与完整批量删除和成组移动。布局、样式、快捷键及 Rust 编辑语义不变。

| 6,000 片段项目，选择最后 1,000 项 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 保留选择数量 | 1,000 | 1,000，逐项 ID 一致 |
| 挂载片段元素 | 1,140 | 140 |
| 页面元素数量 | 5,040 | 1,040 |
| MCP 选择请求往返 | 344.2 ms | 122.0 ms |

这是同机同负载各一次运行的比较，不能据此声称所有操作均快 65%。6,000 片段项目首次打开到就绪约 1.34 秒，较旧基线约 0.95 秒更慢，并未观察到所有指标统一改善。

组件回归先复现 4 项失败，修复后覆盖：30 次播放头更新不增加无关面板渲染次数、全选千项仍裁剪 DOM、焦点退出后释放屏幕外节点、跨视口成组拖动提交完整选择集合。

## 优化版真实测量

| 指标 | 连续播放 | 600 片段跨段播放 |
| --- | ---: | ---: |
| 采样数量 / 稳定样本 | 202 / 196 | 74 / 62 |
| 首末样本真实间隔 | 64.882 s | 23.828 s |
| 项目帧推进时间 / 真实间隔 | 1.00027 | 1.00021 |
| 媒体相对项目时钟绝对偏差 P95 | 54.97 ms | 60.13 ms |
| 音视频媒体时钟相对差 P95 | 64.71 ms | 73.01 ms |
| MCP 检查往返 P95 | 75.74 ms | 105.03 ms |
| 页面检查耗时 P95 | 1.30 ms | 1.80 ms |
| 挂载时间线片段 | 2 | 14 |

7 次首/中/尾定位均找到独立按项目解析的正确视频/音频片段，解码就绪且无错误；600 片段项目定位往返到稳定约 158–170ms，6,000 片段约 201–205ms。它们包含 MCP 往返、固定等待和轮询，不能当作纯解码 seek 耗时。暂停后节点集合不变，媒体时间和播放头保持稳定，源文件哈希/大小/修改时间未变。

脚本工程回归门限：项目推进率 0.95–1.05、P95 媒体时钟差不超过 150ms、MCP 检查 P95 不超过 500ms、密度项目挂载片段大于 0 且少于 500。这些只用于发现明显回归，**不取代 M2 一帧同步/60fps 发布门槛**。30fps 的一帧约 33.3ms，本次 64.7–73.0ms 的相对时钟差不能报告为达标。

稳定统计排除开头 2 秒及片段边界后 0.5 秒内的状态，并要求至少 65% 样本稳定；原始样本全部保留。脚本还核对非有限时钟值、真实时间推进率、媒体片段身份、暂停节点集合和选择 ID，避免空值或“按钮已响应”造成假通过。
