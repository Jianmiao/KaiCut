## M0：能力探针与范围锁定

### 目标

确认 Tauri 2 是可行基线，锁定 P0 的时间基、媒体格式、项目文件方案和 FFmpeg 构建合规边界。

### 任务

- 建立 Windows 的代表性硬件、系统、WebView2 和 GPU 测试矩阵；macOS 测试矩阵待设备后建立。
- 验证 Tauri shell、Rust ↔ React typed IPC、FFmpeg/ffprobe sidecar 的启动、事件、取消和崩溃恢复。
- 用真实 1080p CFR、VFR、长 GOP、可变音频采样率和损坏媒体做 probe、seek、缩略图和波形探针。
- 固定 P0 媒体矩阵：MP4/MOV、H.264 8-bit、AAC/WAV/MP3、44.1/48kHz、24/25/29.97/30/50/60fps，并覆盖旋转 metadata、单双声道和不支持格式错误。
- 验证时间基、帧率、drop-frame/non-drop、音频主时钟和导出快照规则。
- 评估 Windows Media Foundation/D3D/WASAPI 的 helper 或 FFI 路径。
- 固定 LGPL-only FFmpeg 版本、构建配置、许可证清单和第三方编解码器审查项；默认 LGPL-2.1-or-later，排除 GPL/nonfree/version3-only 组件。
- 第一阶段决定 `.kaicut` 单文件 JSON 的 schema v1 和迁移策略；目录包作为后续兼容版本，不进入本次空壳。

### 验收标准

- Windows 干净构建可以打开测试窗口并正确启动、停止 sidecar。
- 至少一段代表性视频可完成首帧、精确 seek 和音频输出探针，并记录误差。
- M0 记录明确的 Tauri 继续条件；若关键能力失败，记录 Electron 切换决定与范围影响。
- 当前许可证、Windows 签名和日志脱敏风险都有负责人和下一步；macOS 公证明确列为待设备后的独立事项。

## M1：项目基础与媒体资产

### 目标

完成项目中心、项目文件 v1、媒体导入和可恢复保存。

### 任务

- 定义项目中心、新建、打开、最近项目和项目路径错误流程。
- 定义同一项目被外部修改、同时打开和锁文件冲突时的重新加载、另存为和保留当前编辑策略。
- 实现 `.kaicut` 单文件 JSON v1、保存、基础 schema 校验和未来目录包迁移预留。
- 建立媒体资产索引、元数据、缩略图、基础波形、离线状态和重新链接流程。
- 接入打包的 LGPL ffprobe，异步返回时长、尺寸、帧率、音频采样率/声道和旋转 metadata；探测结果只保留在运行时状态，不进入 `.kaicut`。
- 设计缓存目录和清理策略，确保缓存不可用时仍能打开项目。
- 设定缓存占用显示、最低剩余空间阈值、自动清理和导出目标已存在时的版本化/确认策略。
- 为媒体、项目文件、恢复和导入错误建立可读的日志与状态文案。

### 验收标准

- 导入视频、音频和图片不会阻塞界面，失败项不会阻止其他素材继续处理。
- 导入后的探测在后台完成；缺失、未链接、超时或 ffprobe 失败会保留明确状态和原因，不阻塞项目打开或保存。
- 强退后可以恢复最近一次有效编辑；临时文件或损坏缓存不会覆盖有效 manifest。
- 移动原始媒体后，项目显示离线并能通过重新链接恢复，不静默绑定错误文件。
- manifest schema、迁移和缓存删除测试通过。
